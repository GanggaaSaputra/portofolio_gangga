# Gangga's Web Developer Portfolio

Welcome to my personal web developer portfolio! This repository contains the source code for my portfolio website, designed to showcase my skills in full-stack web development, backend data systems, and IT hardware consultation.

## 🚀 Live Demo
*(You can add your Vercel deployment link here later, e.g., https://portofolio-gangga.vercel.app)*

## ✨ Key Features
- **Modern UI/UX:** Built with a clean, responsive layout using Tailwind CSS v4.
- **Smooth Animations:** Integrated with Framer Motion for elegant scroll and hover transitions.
- **Dark/Light Mode:** Intelligent theme switching that respects system preferences and saves user choice in `localStorage`.
- **Working Contact Form:** Fully functional contact form powered by Web3Forms.
- **Dynamic Project Showcase:** Detailed case studies of my latest work, including a **Laptop Sales Forecasting System** utilizing the Triple Exponential Smoothing (TES) algorithm.

## 💻 Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons & Assets:** Heroicons, Custom SVGs
- **Form Handling:** Web3Forms
- **Backend/Database (Featured Projects):** Node.js, Express, MySQL

## 🛠️ Getting Started
To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GanggaaSaputra/portofolio_gangga.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd portofolio_gangga
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
